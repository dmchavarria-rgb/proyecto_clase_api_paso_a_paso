# Carpeta 13 - Integración final suave

Práctica sencilla para cerrar el proyecto integrador con JavaScript.

## Contenido

- `index.html`: login simulado para estudiantes.
- `home.html`: panel principal para estudiantes.
- `index-docente.html`: login resuelto para docente.
- `home-docente.html`: panel resuelto para docente.
- `js/login.js`: archivo para que el estudiante complete.
- `js/home.js`: archivo para que el estudiante complete.
- `js/login.docente.js`: versión resuelta y comentada línea por línea.
- `js/home.docente.js`: versión resuelta y comentada línea por línea.
- `css/style.css`: diseño listo.
- `docs/ENUNCIADO_CARPETA_13.md`: instrucciones de la actividad.
- `docs/GUIA_DOCENTE.md`: guía rápida para explicar en clase.
- `docs/PASOS_GITHUB_PAGES.md`: guía básica de publicación.
- `docs/PLANTILLA_INFORME.md`: plantilla corta de informe.

## Librerías usadas

- Bootstrap
- SweetAlert2
- Toastify
- Chart.js

## APIs usadas

- Países: `https://countries.dev/countries`
- Clima: `https://api.open-meteo.com/v1/forecast`

## Recomendación

Ejecutar con Live Server para evitar problemas al cargar recursos externos.
